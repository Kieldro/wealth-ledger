# Android app

The dashboard's site wrapped as an Android app: a [Trusted Web Activity](https://developer.chrome.com/docs/android/trusted-web-activity)
(the installed web app, see "Installable app" in `dashboard/README.md`, shown full screen by Chrome on the phone).
Generated by Google's [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) from `twa-manifest.json`; nothing
from the ledger is in the app, which only opens the site.

- **Package** `life.keo.finance`, host `finance.keo.life`, start `/`. Version: `appVersionName` / `appVersionCode` in
  `twa-manifest.json` (Play needs a higher `appVersionCode` for every upload).
- **Full screen** only while `https://<host>/.well-known/assetlinks.json` lists the package and the SHA-256 fingerprint
  of the key the installed app is signed with (`dashboard.android` in personal.json); otherwise the app still works
  but shows a browser bar.

## Tools (once per machine)
- Bubblewrap CLI in `~/.bubblewrap/cli` (`npm install --prefix ~/.bubblewrap/cli @bubblewrap/cli`), with its JDK 17 and
  Android SDK (`~/.bubblewrap/config.json` says where; the SDK licences must be accepted once:
  `yes | JAVA_HOME=<jdk> ~/.bubblewrap/android_sdk/tools/bin/sdkmanager --sdk_root=$HOME/.bubblewrap/android_sdk --licenses`).
  Gradle and the Android build libraries are cached in `~/.gradle`.
- `secret-tool` (package `libsecret-tools`) for the keystore password.

## Build
```sh
android/build.sh
```
Writes `build-out/wealth-ledger-<version>.aab` (upload to Google Play) and `build-out/wealth-ledger-<version>.apk`
(sideload: `adb install -r ...`), both signed with the upload key, and prints the signing certificate's SHA-256.
`build-out/`, Gradle's `build/` folders and `local.properties` are git-ignored.

After changing `twa-manifest.json` (or the site's icons or colours), run `~/.bubblewrap/cli/node_modules/.bin/bubblewrap update`
in this folder to regenerate the project (add `--skipVersionUpgrade` to keep the version), review the diff, then build.

## Signing
- **Upload key:** `~/.config/wealth-ledger/android/upload-keystore.jks` (outside the repo, folder 0700, file 0600; alias
  `upload`, PKCS12, RSA 4096). Its password is in the GNOME login keyring:
  `secret-tool lookup service wealth-ledger-android key upload`. `build.sh` hands it to apksigner/jarsigner through an
  environment variable, never on a command line. Back both up somewhere safe: losing the upload key means asking
  Play support to reset it.
- **App-signing key:** with Play App Signing (the default for new apps), Google keeps the key that signs what users
  install and re-signs every upload. After the first upload, copy its SHA-256 from Play Console (Setup > App signing)
  into `dashboard.android.sha256_cert_fingerprints` in personal.json next to the upload key's, and restart the
  dashboard service, so Play-installed copies open full screen too.
- Check a fingerprint against the live file:
  `curl -s https://finance.keo.life/.well-known/assetlinks.json`, or Google's checker
  `https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://finance.keo.life&relation=delegate_permission/common.handle_all_urls`.
